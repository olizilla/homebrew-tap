# Olizilla Tap

## How do I install these formulae?

`brew install olizilla/tap/<formula>`

Or `brew tap olizilla/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "olizilla/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
